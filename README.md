# CS_for_TB_UAVs
Система управления стендом для имитации БПЛА, а именно для управления его моторами

### Задачи:
1. Упралвение стендом с ноутбука, подключаемого через bluetooth или по кабелю
2. Задание команд для стенда, на подобие
    * `скороподъемность <скорость> <время>`
    * `полёт <направление> <скорость> <время>`
    * `угловая скорость <скорость> <время>`
    * `тангаж <угол/радианы> <время>`
    * `крен <угол/радианы> <время>` 
    * `рысканье <угол/радианы> <время>`
3. Формирование из команд сценариев и их воспроизведение
4. Сохранение сценариев в файл их воспроизведение из него
